# Results Directory

This directory is reserved for result data that may be archived with the
figshare artifact.

Recommended subdirectories:

- `coverage/`: coverage time-series such as `coverage.csv`.
- `bugs/`: bug-finding outputs such as `found_bugs.txt`.
- `raw/`: raw or compressed run outputs required for reproducibility.

Large result files can also be stored outside the GitHub repository and added
only to the figshare archive. If large files are added here temporarily, record
their checksums in the figshare package.
